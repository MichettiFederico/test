1Conexión con tu GitHub

¿Cómo creo el token? (1 minuto)

Entrá a github.com/settings/personal-access-tokens/new y completá:

• Repository access: Only select repositories → elegí tu repositorio del bot.
• Permissions → Repository, todos en Read and write: Contents, Secrets y Actions.
• Vencimiento: el que prefieras (podés borrarlo cuando quieras).

Copiá el token que empieza con github_pat_ y pegalo arriba.

Sin token (modo manual)

Si preferís no usar un token, copiá esta configuración y pegala en el archivo bot/config.json de tu repositorio (lápiz de edición en GitHub). El mail y la cuenta de envío se cargan a mano en Settings → Secrets and variables → Actions.

Herramienta educativa. No es recomendación de inversión. El panel no guarda tu mail ni tus claves en ningún servidor: habla directamente con la API de GitHub desde tu navegador.
